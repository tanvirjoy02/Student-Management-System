# 🎓 Student Management System (C++)

A simple, interactive console-based application built in C++ to manage student records. This project allows users to add new student information and view existing student records easily.

---

## 📌 Features

* **Add Student:** Input and store student details such as ID, Full Name, and CGPA.
* **View All Students:** Displays a list of all added students in a formatted output.
* **Input Buffer Handling:** Handles spaces in names seamlessly using `getline()` and `cin.ignore()`.
* **Dynamic Storage:** Uses `std::vector` to store student records dynamically during execution.

---

## 🛠️ Tech Stack & Concepts Used

* **Language:** C++
* **Data Structures:** `std::vector`, `struct`
* **Concepts:** Object-style structuring with `struct`, loops (`while`), conditional flow (`if-else`), standard I/O streams (`cin`, `cout`).
